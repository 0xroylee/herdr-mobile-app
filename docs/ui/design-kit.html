herdr mobile design kit

The tokens and components the app is built from, in graphite and paper. The written spec, with every value and rule, is design-kit.md; the screens are in mockups.html. Status marks and list rules follow herdr-app 0.1.10.

Chrome stays monochrome; only status, focus and destructive actions get color. Components use these names, never a hex.
