herdr mobile: tasks, Reminders-style

A proposal for a second direction. The official Herdr app already shows which agents need you and lets you reply, so this pass puts tasks first: you write what you want done, the app hands it to an agent in a project, and the list shows how far each one got. The layout follows iOS Reminders, with smart lists on top, projects below, and one row per task with a circle you check off. Colors, type and status marks still follow design-kit.md. The v1 screens are in mockups.html.

Decisions

  1. Projects are Herdr spaces, with their folders and order from Herdr.
  2. Agents started on the Mac appear as tasks tagged from Herdr; idle ones start under Done.
  3. go starts the agent at once; there is no not-started state or Start pill.
  4. The task starts Claude Code or Codex: Herdr's window receives its task field, and core receives [program, "--", task]; one-word and dash-leading program tasks are refused.
  5. Done uses the task's status message or terminal screen text for its summary; no hooks or agent configuration changes.
  6. Scheduled tasks are for a later version.
  7. Plain terminals and shells open from a project's ⋯ menu, under Terminals; there is no Terminals tab.
  8. Projects have no colors; color marks task status.
